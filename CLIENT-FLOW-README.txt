CLIENT SOCIAL PROFILES
Each talent/client opens a dedicated detail URL:
star.html?slug=<client-slug>

The detail page now shows the client's image, role/bio, stats, and verified social profile icons when a real public URL is available. Social icons open the client's profile in a new tab. Unknown social URLs are intentionally left empty rather than pointing to the wrong account.
